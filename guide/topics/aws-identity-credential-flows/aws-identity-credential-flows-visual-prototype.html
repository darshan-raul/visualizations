# The provider renews temporary credentials when supported.

The provider selects credentials and may refresh them; application code should not paste a temporary set into its configuration.

aws sts assume-role-with-web-identity \
  --role-arn arn:aws:iam::222222222222:role/ReportReader \
  --role-session-name ci-report \
  --web-identity-token file://token.jwt

# Returns temporary AWS credentials after trust validation.

This exchange accepts a trusted identity token and does not require pre-existing AWS keys.

aws sts assume-role-with-saml \
  --role-arn arn:aws:iam::222222222222:role/ReportReader \
  --principal-arn arn:aws:iam::222222222222:saml-provider/CompanyIdP \
  --saml-assertion [BASE64_ASSERTION]

# Returns temporary AWS credentials.

The SAML assertion is proof supplied by the IdP. The response is an AWS credential set.
