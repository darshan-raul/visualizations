ACTIVE VIEW · VFS RESOLUTION PIPELINE

How open("/srv/site/index.html") Becomes Disk Sectors

The kernel does not search the physical disk for the string "/srv/site/index.html". It navigates a chain of cached in-memory structures before ever invoking device I/O.

STEP 1: PATHNAME Path String /srv/site/index.html parsed component by component
STEP 2: RAM CACHE Dentry Cache Resolves names to Inode #262145 via dcache hash
STEP 3: METADATA Inode Object Mode 0644, UID 33, Size 4.2KB, nlink=1, Extent Tree
STEP 4: PAGE CACHE Page Cache (RAM) 4KB memory pages cached from block device
STEP 5: DISK ext4 /dev/vdb1 Physical NVMe blocks #839210–839212
CAPACITY: DATA BLOCKS (df -h) 38% Used · 62 GB Free
CAPACITY: INODES (df -i) 99.8% Used · 142 Inodes Free
Operational Takeaway: Free disk bytes do not guarantee you can create a file. If automated logging or session files exhaust available inodes, the kernel returns ENOSPC: No space left on device even when gigabytes of data block storage remain empty!

Inode Metadata & Link Counts

The directory entry links the name to the inode. When rm unlinks a file, i_nlink drops to 0, but the inode survives as long as any process holds an open File Descriptor.

ACTIVE VIEW · KERNEL PACKET JOURNEY

From Hardware Interrupt to Application Socket Buffer

A port is not a physical socket—it is an index in the kernel's protocol table. When a packet arrives, it must survive multiple filtering and routing decisions before reaching the socket queue.

STAGE 1: HARDWARE NIC RX Ring DMA transfers packet frame; NAPI SoftIRQ schedules kernel processing
STAGE 2: NETFILTER PREROUTING Hook Connection tracking (conntrack) and DNAT translation
STAGE 3: ROUTING Routing Decision (FIB) Is destination local host or forwardable to another interface?
STAGE 4: SOCKET TCP :443 Receive Queue Segment queued in sk_buff; worker awakened via epoll
INTERACTIVE BIND ADDRESS EXPERIMENT

Wildcard Bind (0.0.0.0): The kernel accepts TCP handshakes addressed to any IP configured on any local interface (eth0, lo, or container bridges). This is required for public web services.

ACTIVE VIEW · VIRTUAL ADDRESS SPACE

The Architecture of a Running Process

When the kernel executes an ELF binary via execve(), it creates a 64-bit virtual address space mapped through multi-level page tables to physical RAM frames.

0xFFFFFFFFFFFFFFFF — KERNEL SPACE (High Memory) Protected page tables; accessible only on Ring 0 syscall entry
STACK (Grows Downward ↓) Local variables, function return frames, stack pointers (RSP)
MEMORY MAPPING SEGMENT (mmap) Shared libraries: libc.so, libssl.so, open file descriptors
HEAP (Grows Upward ↑ via brk/sbrk/malloc) Dynamic runtime memory allocations (HTTP response buffers)
BSS & DATA (Global Variables) Initialized and zero-initialized static program state
TEXT / CODE SEGMENT (Read-Only) Compiled machine instructions loaded from /usr/sbin/nginx
Process State Machine Note: Processes in state D (Uninterruptible Sleep) are waiting for direct hardware/disk I/O and cannot be terminated, even with kill -9! The kernel protects filesystem integrity by shielding D-state tasks until the controller returns or times out.

ACTIVE VIEW · HIERARCHICAL PATH RESOLUTION GATE

How the Linux Kernel Evaluates File Permissions

Linux does not check permissions on the leaf file in isolation. To read /srv/site/index.html, the kernel walks from root /, evaluating execute (+x) permissions at every directory gate.

GATE 1: ROOT DIRECTORY / (root) Mode: 0755 (drwxr-xr-x)
Check: other has +x
✓ GRANTED
GATE 2: MOUNT POINT /srv Mode: 0755 (drwxr-xr-x)
Check: other has +x
✓ GRANTED
GATE 3: PARENT DIRECTORY /srv/site Mode: 0750 (drwxr-x---)
Worker UID 33 not in group
✗ DENIED (EACCES)
GATE 4: TARGET FILE index.html Mode: 0777 (-rwxrwxrwx)
Check: Read bit
NOT REACHED!
Simulation: Fix Parent Directory Traversal

Grant group search permission to www-data so the worker can traverse into /srv/site.

IDENTITY INSPECTOR

Process Credential Vector

Linux maintains four distinct UIDs per process: Real (who started it), Effective (setuid operations), Saved (temporary privilege drop), and FSUID (used exclusively for filesystem checks).

uid=33(www-data) gid=33(www-data) groups=33(www-data)
