08 / OPERATING LOOP

Prove the recovery path before you need it.

  1. 01Choose retentionStart from the oldest recovery time your system needs.
  2. 02Observe the rangeRead earliest and latest restorable times from RDS.
  3. 03Preserve a pointTake a manual snapshot when one state must last longer.
  4. 04Decide before deletionFinal snapshot and retained automated backups are separate.
